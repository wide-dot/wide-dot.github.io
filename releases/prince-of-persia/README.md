# Prince of Persia

## Clavier

| Touche | Action |
|---|---|
| J / L | Courir à gauche / à droite, se retourner |
| I | Sauter, grimper |
| K | Se baisser, descendre |
| U / O | Sauter en avant à gauche / à droite |
| Espace | Épée, ramasser, boire ; maintenu : s'accrocher |
| Maj + J / L | Pas prudent |
| I / K en combat | Parer / reculer |
| ENT | Temps restant |
| STOP | Pause |
| CNT-A | Recommencer le niveau |
| CNT-R | Retour au titre |
| CNT-S / CNT-N | Son / musique |
| CNT-G | Sauvegarder (à partir du niveau 3) |
| CNT-L | Reprendre la partie (écran titre) |

## Manette

| Manette | Action |
|---|---|
| Gauche / droite | Courir, se retourner |
| Haut | Sauter, grimper |
| Bas | Se baisser, descendre |
| Haut + gauche / droite | Sauter en avant |
| Bas + avant | Ramper |
| Bouton | Épée, ramasser, boire ; maintenu : s'accrocher |
| Bouton + gauche / droite | Pas prudent |
| Haut / bas en combat | Parer / reculer |
