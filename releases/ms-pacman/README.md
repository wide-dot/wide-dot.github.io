# Ms. Pac-Man

## Manette

| Manette | Action |
|---|---|
| Directions | Diriger Ms. Pac-Man |
| Fire | Mettre une pièce, puis lancer la partie |
| Haut, bas, gauche, droite, fire | Pilote automatique (réseau de neurones), marche / arrêt |

## Clavier

| Touche | Action |
|---|---|
| Une touche | Changer le port de la carte son (validé au bout de 2 s) |
